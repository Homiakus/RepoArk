# RepoArk v0.2.0 implementation notes

v0.2 turns the v0.1 Git mirror/GitLab utility into a broader disaster-recovery control plane.

## Added

- Ed25519 detached manifest signing and verification.
- Release asset download/index/hash verification.
- GitHub Discussions GraphQL capture.
- Issue comments, PR review comments and per-PR reviews.
- GitHub Packages metadata/version capture.
- Optional GHCR OCI archive export with `skopeo`.
- Official GitHub user/org migration archive command.
- Real rotating recovery drills.
- Prometheus-compatible metrics and health/readiness/status endpoints.
- Generic webhook + Telegram notifications using environment-only secrets.
- rclone off-site backend alongside restic, suitable for externally configured S3/MinIO remotes.
- Manifest warning accounting so platform-permission failures are visible but do not invalidate valid Git backups.

## Compatibility

v1 configuration files are loaded on top of v2 defaults and promoted to configuration version 2. Existing absolute artifact paths in old manifests remain readable; new manifests use relative paths.

Unsigned historical manifests remain readable. When current configuration requires signing, normal verification expects the latest manifest to have a valid detached signature.

## Validation added

- Ed25519 sign/verify + tamper test.
- Official migration API contract test with archive checksum sidecar.
- Real Git recovery drill test.
- Existing real Git bundle restore and empty-repository restore tests retained.
- LFS archive round-trip retained.
