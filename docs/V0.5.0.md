# v0.5.0

RepoArk v0.5 introduces the durable orchestration plane: SQL-backed state, leased jobs, per-repository schedules, immutable point-in-time generations, continuous GitLab mirror follow-ups, mTLS agents and control-plane observability.

The release intentionally keeps write-capable agent APIs on a dedicated mutual-TLS listener instead of adding unauthenticated mutation endpoints to the web dashboard.
