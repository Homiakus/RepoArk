# RepoArk v0.6.0 Technical Summary

RepoArk v0.6 turns the durable v0.5 scheduler into a high-availability backup **data plane**.

The release introduces encrypted generation replication, destination CAS hydration, topology-aware placement, durable relay leases, online quorum health, data-aware restore failover/failback, configurable agent labels and approval-gated recovery.

Core safety invariants:

1. A worker is not a replica. Restore routing requires an online `ready` generation copy.
2. The relay is not a trust anchor. Replication payloads are encrypted to the destination key before upload.
3. The database is not proof of data. Target installation verifies the generation's detached signature/checksums before reporting `ready`.
4. Replication factor alone is not topology. Optional failure-domain rules prevent same-zone replicas from satisfying HA health.
5. Transfer spools are leases, not permanent files. Every accepted relay has durable metadata and expiry.
6. An approved restore is not an executed restore. State remains explicit until the leased job succeeds.
7. CAS replication is reachability-driven. Orphaned source CAS objects are not propagated.
